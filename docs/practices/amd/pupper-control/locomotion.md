# Pupper Locomotion｜强化学习运动策略

这个方向的目标不是手工编排某一种步态，而是训练一条完整的 **locomotion policy**：Pupper 接收期望的前进、横移与转向速度，并在仿真中持续输出关节动作，稳定跟踪指令。

## 实验目标

- 将 Pupper 仿真封装为标准 Gymnasium 环境；
- 明确 Observation、Action 与控制频率；
- 用可解释的奖励项训练 PPO 策略；
- 完成速度指令跟踪与 Domain Randomization；
- 在 AMD 平台上记录训练效率、推理表现与实验结果。

## 实验主线

| 模块 | 内容 | 阶段产出 |
|---|---|---|
| 01 实验介绍 | 明确任务、评价指标与对照组 | 实验计划与验收标准 |
| 02 Gymnasium 环境 | 组织 `reset`、`step`、终止条件和并行环境 | 可运行的训练环境 |
| 03 Observation & Action | 设计本体状态、速度指令、历史观测与关节动作 | 状态与动作接口说明 |
| 04 Reward Design | 组合速度跟踪、姿态稳定、能耗与动作平滑等奖励 | 奖励消融表 |
| 05 PPO 训练 | 配置训练、评估、日志与 checkpoint | 可回放的策略文件 |
| 06 Domain Randomization | 随机化动力学、接触、观测噪声与延迟 | 鲁棒策略与对照实验 |
| 07 速度指令跟踪 | 测试前进、横移、转向和组合命令 | 跟踪曲线与演示视频 |
| 08 AMD 平台实验 | 记录环境、运行参数、训练与推理性能 | 可复现实验记录 |
| 09 实验结果 | 汇总指标、失败案例与改进方向 | 项目报告 |

## 关键评价维度

训练奖励只能说明优化过程是否在推进，不能单独代表策略可用。最终至少从以下维度评价：

- **速度跟踪**：实际线速度、角速度与目标指令之间的误差；
- **稳定性**：机身姿态、跌倒率和单次持续运行时间；
- **动作质量**：关节动作是否平滑，是否出现高频抖动或异常冲击；
- **效率**：力矩、功率或其他可获得的能耗代理指标；
- **鲁棒性**：面对动力学偏差、接触变化、噪声与外部扰动时的性能退化。

## 复用基础教程

本实验直接复用 [《从零到一搭建四足机器人》](/docs/practices/quadruped/cs123/intro) 中已经完成的 Pupper 模型和底层控制，不在这里重新展开 PD 控制、运动学或本体搭建。需要回顾强化学习环境与 PPO 基线时，可参考其中的 [策略训练章节](/docs/practices/quadruped/cs123/rl-gait)。

## 完成标准

- 策略能够连续响应多段速度与转向命令，而不是只完成单一前进动作；
- 训练配置、随机种子、模型 checkpoint 和评估脚本能够对应起来；
- 至少完成一组奖励或 Domain Randomization 的对照实验；
- AMD 平台实验记录包含环境信息、关键参数、指标与结论；
- 失败案例被保留并解释，而不是只展示表现最好的一次回放。

完成后，可以把训练得到的策略封装成 `walk`、`turn`、`stop` 等技能，继续进入 [Pupper VLA](./vla)。
