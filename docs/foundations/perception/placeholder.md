# 定位、触觉与传感器标定

机器人不是直接生活在神经网络的张量里，而是生活在一组带时间戳、带坐标系、带噪声和延迟的传感器数据里。感知系统既包括外部环境感知，也包括本体状态估计和传感器标定。
